# Bulk-RNA-Sequencing-of-MYORG-mutant-astrocytes-in-PFBC
R scripts for analyzing bulk RNA-seq data to investigatel impact of MYORG mutations in Primary Familial Brain Calcification (PFBC). Using mouse astrocyte models, the project implements differential expression analysis (limma-voom), Gene Set Enrichment Analysis, and GO enrichment (clusterProfiler) across brain regions and culture media.
